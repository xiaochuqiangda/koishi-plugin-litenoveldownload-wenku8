# koishi-plugin-litenoveldownload-wenku8
- 请使用最新稳定版本0.1.4

- 本插件基于www.wenku8.net网站提供下载服务，请在使用前前往注册账号
- 要求回复和一对一两个配置项按需开启或关闭
- 标注无法下载的书籍是由于版权问题网站未提供下载直链
- 搜索指令后+空格+更新/热门/完结/动画化 可以指定当次搜索结果排序
- 所有指令的根指令就是配置页自定义的搜素指令，自行替换即可
- 黑名单指令 （指令）.blacklist add 123456789/（指令）.blacklist remove 123456789/（指令）.blacklist.list
- 小说TXT文件使用如QQ浏览器等有阅读模式的软件使用最佳
- 如有侵权请联系，侵删。搜索和下载到的所有内容仅用于参考和学习，请勿外传。如有任何问题与建议请提issue

---

## 功能特性

- **三种搜索模式**
  - 按标题搜索：`wenku8 <关键词>`
  - 按标签搜索：`wenku8 tag <标签>`
  - 按列表浏览：`wenku8 list`（支持按更新、热门、完结、动画化排序）

- **交互式会话**
  - 搜索后进入交互等待模式
  - 支持「下一页」「上一页」翻页浏览
  - 支持「下载+序号」直接下载对应书籍
  - 支持「取消」随时退出搜索

- **文件下载与缓存**
  - 自动下载完整 TXT 小说文件
  - 通过 OneBot 原生 API 直接上传，文件名正确、格式可识别
  - 支持自定义缓存数量，超出上限自动删除旧文件

- **合并转发（可选）**
  - 开启后搜索结果以合并转发卡片形式展示
  - 需要 NapCat 等支持自定义合并转发的 OneBot 实现

## 安装方法

在 Koishi 控制台「插件市场」或「依赖管理」中安装：

```bash
npm install koishi-plugin-wenku8-search
```

然后在「插件配置」中启用并填写账号信息。

## 配置说明

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `username` | string | 是 | - | 轻小说文库（wenku8.net）账号 |
| `password` | string | 是 | - | 轻小说文库密码 |
| `commandName` | string | 否 | `wenku8` | 搜索指令名称，可自定义 |
| `defaultSort` | union | 否 | `lastupdate` | 列表浏览默认排序方式 |
| `downloadPath` | string | 否 | `./wenku8-downloads` | 下载文件保存路径（绝对或相对路径） |
| `timeout` | number | 否 | `60` | 搜索会话超时时间（秒） |
| `useForward` | boolean | 否 | `false` | 是否使用合并转发展示搜索结果 |
| `maxCache` | number | 否 | `5` | 缓存文件数量上限，超出将删除最旧的文件 |

> **注意**：`username` 和 `password` 必须填写，否则无法获取下载链接。

## 使用教程

### 1. 按标题搜索

```
wenku8 魔法禁书目录
```

机器人返回搜索结果列表，进入交互模式。

### 2. 按标签搜索

```
wenku8 tag 校园
```

搜索包含「校园」标签的所有小说。

### 3. 按列表浏览

```
wenku8 list
```

按默认排序（可在配置中修改）浏览小说列表，可选：
- `lastupdate` — 按更新时间
- `allvisit` — 按热门程度
- `fullflag` — 只看完结作品
- `anime` — 只看动画化作品

### 4. 交互指令（搜索后使用）

| 指令 | 说明 |
|------|------|
| `下载+序号` / `dl+序号` | 下载对应书籍，如 `下载1` |
| `下一页` / `n` | 查看下一页搜索结果 |
| `上一页` / `p` | 查看上一页搜索结果 |
| `取消` / `cancel` | 退出搜索会话 |

> 下载失败（如无书源、网络异常）时，会话**不会退出**，会提示：
> 「下载失败，您可以继续选择其他书籍下载或取消等待。」

## 文件下载说明

- 下载的小说为 **UTF-8 编码 TXT 文件**
- 文件名格式：`《小说名》_书籍ID.txt`
- 文件保存在配置的 `downloadPath` 目录中
- 发送给 QQ 时保留 `.txt` 扩展名，可直接用 QQ 浏览器或系统记事本打开
- 缓存文件按数量上限管理，旧文件自动清理

---

## 注意事项

1. **账号要求**：wenku8 部分书籍需要登录后才能下载，请务必填写正确的账号密码。
2. **下架书籍**：若书籍因版权问题已下架，会提示「无书源」，无法下载。
3. **合并转发**：`useForward` 需要 NapCat 等支持 `send_group_forward_msg` / `send_private_forward_msg` 的 OneBot 实现，普通 go-cqhttp 可能不支持自定义合并转发。
4. **超时机制**：用户无操作超过 `timeout` 秒后，会话自动结束。
5. **路径问题**：`downloadPath` 建议使用绝对路径，或确保 Koishi 进程有权限写入该相对路径。

## 常见问题

**Q：为什么文件发送后文件名正确但之前会乱码？**  
A：旧版本使用 `h.file(Buffer)` 导致 Koishi OneBot 适配器误将文件内容 base64 作为文件名。当前版本已修复，直接通过 OneBot 原生 API 上传本地文件。

**Q：下载完成后文件夹里文件被删了？**  
A：请检查 `maxCache` 配置。如果设为较小数字（如 1~2），新下载会触发旧文件清理。建议设为 5 或更大，或设为 0 表示不限制（不推荐，可能占用大量磁盘）。

**Q：合并转发显示不出来？**  
A：请确认使用的是 NapCat 或其他支持自定义 node 合并转发的 OneBot 实现，并在配置中开启 `useForward`。
